Zero-build HTML/CSS/JS boilerplate

Welcome to the boilerplate

This page has no framework and no bundler — just plain HTML, CSS, and JS loaded straight in the browser. It exists to show the design system in styles/tokens.css working end to end, so a new product can fork this repo and start from a real foundation instead of a blank file.
